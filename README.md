# Collapse

Collapse is a standalone Garry's Mod gamemode focused on last-player-standing survival in physics-driven arenas.

## Status

Initial native gamemode scaffold. Gameplay, rounds, elimination, arena behavior, and UI have not been implemented yet.

## Installation

Copy `gamemodes/collapse/` into your Garry's Mod installation's `garrysmod/gamemodes/` directory, then select the `collapse` gamemode when starting the server.

## Project boundaries

Collapse is an independent gamemode project. It does not require GameWeenies infrastructure or a third-party gamemode framework.
